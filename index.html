Final Year Project

Enabling Vision-Language Understanding in Humanoid Robots for Object Identification and Grasping Tasks

Humanoid robots usually need objects to be pre-programmed before they can pick them up. This project integrates a vision-language model with a humanoid robot so it can take a natural-language instruction, such as "pick up the red cup", locate and identify the matching object in its camera view, and turn that into a grasping action. The work links computer vision, language understanding and robot motion control into a single pipeline, and evaluates how reliably the robot identifies and grasps objects under different conditions.
